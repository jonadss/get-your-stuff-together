## Installation

1. Im Browser zu **Actions** → **Build Executables** → neuesten (grünen) Run öffnen.
2. Ganz unten bei **Artifacts** auf `financ-app-windows` (oder `financ-app-linux`) klicken → lädt eine `.zip` herunter.
3. ZIP entpacken (Rechtsklick → "Alle extrahieren") – **nicht** direkt aus dem ZIP
   heraus starten, sonst gibt es Fehler.
4. Im entpackten Ordner `financ-app.exe` doppelklicken (unter Linux: `chmod +x financ-app` und dann `./financ-app`).
5. Falls Windows SmartScreen warnt: **"Weitere Informationen"** → **"Trotzdem
   ausführen"** klicken (unsignierte .exe, daher die Warnung).
